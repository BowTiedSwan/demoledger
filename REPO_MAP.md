## packages/shared: contracts every other package imports

- `src/filters.ts`: Tool args and REST query schemas (strict: an unknown key such as `tenant_id` fails).
- `src/ask.ts`: `/api/ask` request, stream data parts, tool result shapes, error codes and copy.
- `src/visual.ts`: `present_visual` args and the `visualSpec` catalog contract (ADR 0009).
- `src/enums.ts`: Status, direction, period, guard verdict, audit status, `TOOL_NAMES`.
- `src/money.ts`: `formatMinorUnits`: the only place minor units become display strings.
- `src/dates.ts`: UTC period resolution (half-open ranges, ISO week), used by validation, SQL and tests.

## packages/db: the privilege model lives here, not in the app

- `src/schema/index.ts`: Tables: ledger (`transactions`), Better Auth, audit and conversations.
- `src/roles.sql`: Role grants and RLS policies; every change pairs with an assertion in `roles.test.ts`.
- `src/seed/generate.ts`: Pure `generateTransactions(anchor)`; tests derive expected values from it.
- `src/testing/global-setup.ts`: Resets and seeds `demoledger_test` once per vitest run.

## apps/api: one deep module per concern, wired at the `createApp(deps)` seam

- `src/app.ts`: `createApp(deps)`: middleware order and the chained routes (`AppType` for the web client).
- `src/lib/deps.ts`: The seam: LLM, guard, clock, pools, audit and conversation store are injected adapters.
- `src/index.ts`: Production entry: loads config, asserts DB roles at boot, wires real adapters.
- `src/middleware/require-tenant.ts`: The only place a tenant is established: session, then membership re-check.
- `src/repo/transactions.ts`: Repository: the single tenant enforcement point shared by REST and tools.
- `src/repo/with-tenant.ts`: `withTenant`: transaction-local RLS context (`app.tenant_id`).
- `src/tools/index.ts`: `ledgerTools`: tenant bound in the factory closure; strict args validated in `execute`.
- `src/tools/visual.ts`: Builds the visual spec from this request's recorded results; no DB access.
- `src/guard/index.ts`: Guard interface with three adapters: heuristic, Clef (System One), noop for tests.
- `src/orchestrator/index.ts`: `handleAsk`: guard, model/tool loop, answer checks, audit, conversation store.
- `src/orchestrator/grounding.ts`: Answer checks: citation grounding, counts, facts, speculation.
- `src/conversations/index.ts`: Server-stored history; `withTenantUser` sets tenant and user RLS context.
- `src/audit/index.ts`: Append-only audit sink (`ai_requests`, `ai_tool_calls`).

## apps/web: renders contracts, never redefines them

- `src/lib/api.ts`: Typed `hc<AppType>` client; every payload type comes from `@demoledger/shared`.
- `src/lib/chat-parts.ts`: Suggested questions (four from the brief verbatim, plus the chart prompt).
- `src/components/ai-elements/message.tsx`: Hardened markdown: no remote images, same-origin links only.
- `src/components/visual/registry.tsx`: Fixed catalog renderer for validated `data-visual` specs.
- `csp.ts`: Content Security Policy (`img-src 'self' data:; connect-src 'self'`).
- `src/styles/globals.css`: Design tokens: the only place colours, radii and type are defined.

## API routes (generated from `apps/api/src/app.ts`)

| Method | Path | Route middleware, in order |
