### DI shape (`apps/api/src/lib/deps.ts`, chosen in Phase 0)

```ts
createApp(deps: AppDeps)  // returns the chained Hono app; export type AppType = ReturnType<typeof createApp>
interface AppDeps {
  config: AppConfig;                         // parsed env (api-builder: lib/config.ts loadConfig(env))
  db: { reader: Database; app: Database };   // ledger_reader / ledger_app drizzle instances
  auth: AuthLike;                            // api-builder narrows to the concrete Better Auth type
  llm: { model: LanguageModel; provider: string; modelId: string } | null;  // null => llm_unconfigured
  guard: Guard;                              // from @demoledger/shared
  now: () => Date;                           // injected clock for every period resolution
  logger: Logger;
}
// Hono Env: { Variables: { requestId: string; tenant: { userId; tenantId } } }
```

Tests build the app with `createApp({ ...testDeps, llm: { model: new MockLanguageModelV4(...), provider: 'mock', modelId: 'mock' }, guard: noopGuard, now: () => new Date('2026-10-28T12:00:00Z') })`. Nothing under `createApp` reads `process.env`.
